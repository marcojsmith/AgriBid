## Convex

- 2026-11-25 - A lot becomes `sold` in three separate places (`settleLot`, `resolveConsideration` accept, `closeLotEarlyHandler`; `closeLotEarly` patches the lot itself and does not call `settleLot`), so anything that must happen "when a lot sells" needs a hook in each, with a test per path. Anything that `auctions/internal.ts` imports must not import it back (it re-exports `notifyUser`/`formatNotificationRand` from `lib/notify.ts` for that reason). Mocked-ctx handler tests (`publish.test.ts`, `closeAuctionEarly.test.ts`, `mutations_branch.test.ts`) must `vi.mock` `lib/lotPayments`. The hammer price passed on the accept path must come from the top bid, not the lot snapshot (it is already stale there).
- 2026-11-24 - A mutation that throws rolls back every write, including `ctx.storage.delete`, so "delete the bad upload, then throw" cannot work in one mutation; `attachMyDocument` just throws and leaves the file to the orphan sweep. Any new table that references `_storage` must also be added to `REFERENCE_TABLES` in `convex/storageCleanup.ts`, or the sweep deletes its files after a day. `convex-test` stores no `contentType` on `_storage` rows: patch it in the test before checking MIME rules (R1).
- 2026-11-23 - `toLotSummary` fed every lot list and carried `reservePrice`, `sellerId` and `winnerId`, so every public list leaked them even after `getLotById` was fixed (#418). Public summaries now never include them; seller and admin paths use `toOwnerLotSummaries` after an ownership or `requireAdmin` check. When adding a query that returns lots, use `toLotSummaries` and add it to `publicLeaks.test.ts`.
- 2026-11-23 - `resolveBuyerPremium` returns `rate: undefined` for the fee-rows case; sum the active buyer percentage rows (`isBuyerPercentageFee`) and add the fixed buyer fees. `platformFees.value` is already a fraction (settlement does `price * value`), so do not run it through `percentToFraction`.
- 2026-11-23 - `getLotById` used to send `sellerId`, `winnerId`, `sellerEmail` and the reserve amount to every visitor; return booleans (`isSeller`, `isWinner`) and a `reserveState` instead, and mask bidders with a salted per-lot hash (`BIDDER_LABEL_SALT`).
- 2026-11-23 - `lots.imageAngles` is keyed by storage ref while `images` holds resolved URLs; use the resolved `photos` array (`resolveLotPhotos`) when you need both.
- 2026-11-23 - Plain `Error`s thrown from mutations are redacted in production; throw `ConvexError` for anything the client must show (bid rejections).
- 2026-11-24 - The settle cron settles every past-due `assigned` lot and DETACHES unsold ones (`auctionId`/`lotNumber` cleared), so a re-timed demo sale must end after the next weekly reset (live +8d, upcoming +9d) or its lots leave the sale for good and fake bids settle into real fee rows. Also move the sale's own times in the first re-time batch, not the last.
- 2026-11-23 - U+202F (narrow no-break space) renders almost invisibly in Inter, so prices read "R250000"; `formatRand` and the lot card now use U+00A0. Tests that normalise spaces accept both.
- 2026-11-23 - `seed:weeklyReset` used to delete every lot, auction and non-admin profile; it runs against the production showcase, so it now only re-times sales that carry an `auctions.seedId` and removes `mock-*` bids and watches. Anything that must survive a reset (imported lots, photos) needs its own marker; never reintroduce a table-wide wipe there.
- 2026-11-23 - The webuytractors.shop scrape lists the source's own "missing image" placeholder as a relative path (`/images/missing-image-xl.png`) and a few JPEGs are truncated (`sharp` needs `failOn: "none"`); the Wix listing photos are full-size originals, so resize before uploading. Unknown year/hours are stored as 0 (as drafts already do), so every year/hours filter must treat 0 as unknown.
- 2026-11-23 - `getPublishedAuctions` sale summaries read at most 20 lots per status, so Home shows "20+ lots" for larger sales; a cheap exact lot counter would fix it (follow-up).
- 2026-11-23 - No outbid or watch notification exists yet; do not claim one in copy until D9 ships (`WATCHING_SAVED_MESSAGE` vs `WATCHING_MESSAGE`).
- 2026-11-23 - The event page reads a sale's `assigned`, `sold` and `unsold` lots (100 each, `by_status_auctionId`) in `getEventLots` / `getEventFacets`; "Show 24 more" re-runs the list with a larger `limit` (capped at 300) instead of paging, so a sale over 300 lots is flagged `capped`. Sorting by "most watched" reads one counter per read lot, so it is the costliest option. The header search on a sale page sets `?q=` on that page instead of going Home.
- 2026-11-23 - Home's chips and grid need counts per category and make plus watchers and bids per lot, which no query returned. `auctions:getHomeFacets` and `getHomeLots` read a sale's `assigned` lots (bounded to 100 per sale) and are separate queries so picking a chip re-runs only the grid; both still re-run whenever a read lot changes (a bid), so keep the read cap small. A branch that adds a backend query cannot be reviewed against the self-hosted production backend (workers never deploy): run an anonymous local Convex (`CONVEX_AGENT_MODE=anonymous bunx convex dev`, then set `ALLOW_PII_DEV_FALLBACK` and `CLERK_JWT_ISSUER_DOMAIN`, seed with `seed:weeklyReset`) and point `.env.local` at it.
- 2026-11-23 - `prettier --write src` rewrites line endings across the whole tree on Windows checkouts (CRLF) and flags every file as modified; format only the files you changed. A cleanup `git checkout` of "unrelated" files also reverts doc edits made earlier, so re-check `git diff --stat` before committing.
- 2026-09 - Convex `returns` validators reject extra fields, not just `args`. Spreading a whole doc (`{...profile}`) through a hand-rolled validator broke once `profiles` gained `emailVerified` etc. → extend the validator whenever the table schema gains fields (issue #219).
- 2026-09 - `paginationOpts` must be a required validator field for `usePaginatedQuery` type inference; paginated queries cannot return `null` for authz denial (the hook throws) → throw `ConvexError` and catch it with a local error boundary (issue #231).
- 2026-09 - Convex array-field indexes are not "contains" lookups → for two-party data use two scalar indexed fields and union the queries, not a `participantIds` array (issue #231).
- 2026-09 - Rate limits and duplicate checks done as collect-all + JS filter violate the "prefer indexes" rule and are easy to get off by one (`>` vs `>=`) → use an index range and `>=` on the pre-send count (issue #231).
- 2026-09 - Mutation whose handler args are a named interface makes the generated `FunctionReference` infer `never` args → declare the validator once as a `v.object` const, type the handler with `Infer<typeof validator>`, pass the same const to `mutation({ args })` (multi-lot rework, 2026-09-16).
- 2026-09 - Convex `useQuery` returns `T | undefined | null`; `=== undefined` alone does not prove non-null → check both when removing `!` (issue #171).
- 2026-09 - `interface` handler-arg types degrade Convex references to `never`, failing at distant call sites → keep `type` aliases for Convex args types (issue #171 Phase 3). See Build/CI for the lint side.
- 2026-09 - Bulk N+1 in admin views (announcement read counts) → use one indexed batch helper (`batchFetchReadCounts`) plus a single `.collect()` + Set filter, not N x `.unique()`.
- 2026-09 - Storage id string-arg overloads (`storage.delete`/`getUrl`) are deprecated → cast with `as Id<"_storage">`.
- 2026-09 - Internal mutations (e.g. the weekly reset cron) have no caller identity, so admin/env guards like `checkDestructiveAccess` wrongly reject them → don't call identity guards from cron-only internals.
- 2026-09 - Seeds must be idempotent: insert-if-absent by natural unique key, seed keyless tables only while empty → plain re-runs never duplicate.
- Undated - `getMyBids` paginates via `indexOf(cursor) + 1` over an in-memory array → refactor to a real cursor query if per-user bid-on auctions exceed ~1,000.

- 2026-11 - `lots.resolvedBuyerPremiumPct` and `auctions.defaultBuyerPremiumPct` are named "Pct" but hold a fraction (`0.05` = 5%): the backend multiplies them straight onto the price. Use `premiumFromRate` in `src/lib/vat.ts`, and do not divide by 100. `vat_rate_pct` is a real percentage (15 = 15%).
- 2026-11 - Patching a Convex field with `undefined` removes it (that is how `adminUpdateLot` clears `province`), but `convex-test`'s `t.run` returns `null` for a missing field, so assert with `?? undefined` or `not.toHaveProperty`.

- 2026-09 - `vi.mock("./_generated/server")` must expose identity `mutation`/`internalMutation` wrappers or `.handler` is unreachable at runtime (pattern from `presence.test.ts`).

- 2026-09 - Removing an "unnecessary" `?.` in `a?.b?.c` changes short-circuit behaviour → make nullishness visible in the type instead.

## Process

- 2026-09 - Removing legacy tables/fields from the schema after a migration: leftover rows are inert; drop the indexes and migration module in the same cleanup (multi-lot rollout, 2026-09-17).
- 2026-09 - Audit for stubbed "Not implemented"/"Coming soon"/`TODO(#n)` affordances with a repo-wide grep before declaring a feature done (issue #231 follow-up).
- 2026-09 - Pre-existing warnings encountered in unrelated files are left for a separate cleanup commit, not folded into feature work.
- 2026-10 - A 1-minute Convex cron scanning `lots` burned ~450 MB/day per deployment and exhausted the Free plan while the app sat idle; Convex then disables the deployment (no `convex run`, no dashboard edits). Convex crons are static, so gate them in code (settings-backed wrappers in `convex/cronJobs.ts`) and keep new jobs default-off.
- 2026-11 - `convex/tsconfig.json` pins `lib: ES2021`, so `new Error(msg, { cause })` fails type-check there; use `Object.assign(new Error(msg), { cause })` to satisfy ESLint 10 `preserve-caught-error`. Prettier 3.10 breaks the indented `Record` row of the table in `.claude/rules/convex_rules.md`; leave that file unformatted.
- 2026-11 - `convex/storageCleanup.ts` orphan sweep reads only the first batch of `lots`/`profiles`/`auctions` per run and discards the cursor, so files referenced only past that batch look orphaned. Cron is off by default; fix before enabling it. **Fixed in 0.17.36** (sweep is now an action that pages every table to completion and aborts, deleting nothing, if the scan fails; remaining race: an >1 day old file attached to a row mid-sweep).
- 2026-11 - Soft-close extensions have no maximum (each late bid sets `extendedEndTime = now + 2 min`), and the settle crons are off by default, so ended sales stay `published`. Any "ends soon" read must bound the sale `endTime` window on both sides and read recently ended sales separately (newest first), or finished sales fill the cap. A first bid can equal `startingPrice`, so "has bids" must come from the `bids` table, not a price comparison.
- 2026-11 - Admin-authored markdown renders through `react-markdown` with `skipHtml` and no `rehype-raw`; its default URL transform already strips `javascript:` links. Tables, strikethrough and task lists are GFM and need `remark-gfm`, which we deliberately did not add, so legal text must not rely on them. New Convex modules need their entries in `convex/_generated/api.d.ts` (add by hand if you cannot reach a deployment for codegen). Radix `TabsTrigger` activates on `mouseDown`, so use `fireEvent.mouseDown` in tests.
- 2026-11-24 - A caption's own `bg-linear-to-t` sat above the sibling left-edge fade and left a hard photo edge behind the caption: put scrims in their own layers below the fade. Lot counts capped at 20 per status showed "20+ lots" for an 82-lot sale; any count shown to buyers needs a maintained counter (`syncAuctionLotCount` after every write that changes a lot's status, sale or hidden flag), not a capped read.
- 2026-11-24 - `@vercel/og` 1.x (1.0.2, 1.0.3) fails to load under Node (`hb.wasm` is missing from the package); pinned to 0.8.6, which renders with `.woff` fonts. The old bundled Satori throws `Cannot read properties of undefined (reading 'trim')` when a style value is `undefined` (e.g. `left: undefined`), and ignores `right:` with a `width`; spread only defined style keys and use `left`. Vercel treats every file under `api/` as a function, so tests and helpers live in `api/_lib/` (underscore folders are skipped).
- 2026-11-24 - Never run `bun run format` on a branch: on this Windows checkout it rewrites hundreds of untouched files (line endings and wrapping). Format only your own files with `bunx prettier --write <files>`. Web push needs a notification shown for every push (iOS revokes the subscription otherwise), so `public/sw.js` falls back to a generic one on an unreadable payload.
- 2026-11-24 - Web push endpoints are user-supplied URLs the backend POSTs to: only accept https on the known push-service hosts (`isAllowedPushEndpoint`), never any https URL, or the LAN-hosted backend becomes an SSRF relay. Known gaps left on purpose: a device is not unsubscribed on sign-out, and a failed push is not retried (the in-app notification is the fallback).
- 2026-11-24: `web-push@4` is ESM with named exports only. `import webpush from "web-push"` passes vitest (the mock supplies `default`) and tsc, but `convex deploy` (esbuild) fails with "No matching export ... for import default", so the Vercel prod build fails. Mock the module the way it really exports, and treat a first-time dependency in a `"use node"` file as unverified until a real `convex deploy` bundles it.
- 2026-11-24 - Testing Library collapses non-breaking spaces in rendered text before matching, so `getByText("R 5 000")` written with U+00A0 never matches `formatRand` output. Use a plain space in the expected string (the DOM text is normalised, your string is not). The client can import the pure parts of `convex/lib/registration.ts` (it also imports a server helper, but the build tree-shakes it; verified with `bun run build`).
- 2026-11-24 - Convex serves every stored file at `/api/storage/<id>` (and `ctx.storage.getUrl` links) with no access check: the id is the only secret, and it leaks through any query that returns it. Never rely on it for personal documents (ID, passport, address): encrypt before `ctx.storage.store` and serve through an HTTP action that checks the caller. A `registrationDocuments.contentType` field is also needed because the stored blob is `application/octet-stream`. Add a `v.string()` field as `v.optional` when rows already exist, or the schema push fails; `convex-test` `t.run` cannot return a `Uint8Array` (return number arrays).
- 2026-11-25: Tailwind 4 puts utilities in a CSS layer and Clerk injects unlayered styles, so classes passed in Clerk `appearance.elements` (h-[52px], rounded-md, shadow-none) silently lose. Set `appearance.cssLayerName: "clerk"` and declare `@layer theme, base, clerk, components, utilities;` in `index.css`. Verify in the browser; unit tests cannot see it.
