# Roadmap

Shipped work is recorded in [`../CHANGELOG.md`](../CHANGELOG.md); live state is in [`../STATUS.md`](../STATUS.md). The detailed backlog lives in [GitHub Issues](https://github.com/marcojsmith/AgriBid/issues); this file is direction only. Requests can also come via support tickets or direct feedback.

## Near term

- **Optimistic UI updates**: update the UI before server confirmation to cut perceived latency (bidding, listing).
- **Bid history enhancements**: more bid detail, export.
- **Enhanced seller verification**: multi-tier verification with business documentation.
- **Seller analytics**: deeper sales analytics, conversion rates, viewer metrics.
- **PDF condition reports**: printable equipment inspection summaries.

## Medium term

- **Infinite scroll** to replace pagination on large marketplace lists.
- **Advanced search**: saved searches and alerts.
- **Advanced notifications**: SMS and email outbid alerts.
- **Auction recommendations**: AI-powered, based on browsing history.

## Long term

- **AI-powered pricing**: recommend reserve prices from historical sales.
- **AI chatbot support** for bidding and listing queries.
- **Mobile app**: React Native wrapper for on-field bidding.
- **Live auction events**: scheduled "mega-auctions" with simulcast video.
- **Multi-language and multi-currency** support beyond Southern African markets.
- **International shipping integration**: quotes and logistics.

## Considered (no commitment)

- Payment processing for winning bids.
- Escrow (hold funds until delivery).
- Insurance options during transport.

## Technical improvements

- Ongoing: image optimisation, query optimisation, code splitting, unit test coverage.
- Planned: aggressive caching, E2E tests, load testing, public API docs, integration guides.
